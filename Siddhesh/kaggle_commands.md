# Kaggle run sheet

The notebooks in `kaggle/A`, `kaggle/B`, `kaggle/C` are generated by `python build_notebooks.py` (package source is embedded with `%%writefile`).
Authenticate once with an API token from your Kaggle account settings (never commit it):

```bash
export KAGGLE_API_TOKEN=<your token>          # or save it to ~/.kaggle/access_token
```

## ViT notebooks (A then B), GPU T4 x2
Settings: Accelerator **GPU T4 x2**, Internet **On**, input dataset `christopheronyiuke/jaad-video` (the 346 JAAD mp4 clips).

```bash
kaggle kernels push -p kaggle/A --accelerator NvidiaTeslaT4      # ~3-4 h: recipe search, 3 seeds x 5 folds, box-only control, probes
kaggle kernels status siddheshnadkarni/jaad-dense-vit-a           # wait for COMPLETE
kaggle kernels push -p kaggle/B --accelerator NvidiaTeslaT4      # ~4-5 h: needs A's output (kernel_sources in kernel-metadata.json)
kaggle kernels status siddheshnadkarni/jaad-routed-vit-b
```
`kaggle/B/kernel-metadata.json` lists notebook A as a kernel source, so B reads A's `recipe.json`, runs and crop cache. Run A first.

Download only the small result files (the full output contains the crop cache and the JAAD clone):
```bash
kaggle kernels output siddheshnadkarni/jaad-dense-vit-a -p out_A --file-pattern '.*(results_A|results_boxonly|recipe|summary_A)'
kaggle kernels output siddheshnadkarni/jaad-routed-vit-b -p out_B --file-pattern '.*(results_B|hypotheses_B|H2\.csv|H3\.csv|H4\.csv|H5\.csv|summary_B)'
```

## Pedestrian Graph+ notebook (C), optional
Needs the pose cache as a Kaggle dataset:
```bash
python kaggle/C/make_dataset.py               # copies data/samples_ctx/jaad_beh.pkl + data/pose_beh into kaggle/pg_data/
kaggle datasets create -p kaggle/pg_data      # later: kaggle datasets version -p kaggle/pg_data -m "msg"
kaggle kernels push -p kaggle/C --accelerator NvidiaTeslaT4
```
